This is the home for my public projects — write-ups, tools, and experiments.

The site is a Jekyll site with a modern front-end build: Jekyll handles layouts,
Markdown, and content generation, while esbuild bundles the JavaScript and CSS
that ship to the browser. Source for both lives in
[this repository](https://github.com/gl0bsec/gl0bsec.github.io).
